### 📊 Sales Performance Analysis
*Business Problem: Which regions, products, and time periods are driving or dragging revenue?*
- Cleaned and processed transactional sales data using Pandas and SQL
- Built visualisations covering time-series trends, regional heatmaps, and product contribution
- Tracked KPIs: Monthly Revenue, Growth Rate, Average Order Value, Regional Performance
- Tools: Python (Pandas, NumPy), SQL, Matplotlib, Seaborn

### 🔎 Customer Churn Analysis
*Business Problem: Why are customers leaving, and which segments are most at risk?*
- Performed EDA and RFM-based feature engineering to profile high-risk customers
- Analysed behavioural patterns to surface churn drivers
- Delivered findings with retention strategy recommendations
- Tools: Python (Pandas, Matplotlib, Seaborn), SQL

### 🧾 Market Basket Analysis
*Business Problem: Which products are frequently bought together — and how can that drive cross-sell strategy?*
- Applied association rule mining (Apriori) to identify product affinity patterns
- Analysed lift and confidence metrics to recommend bundling and promotion opportunities
- Tools: Python (mlxtend, Pandas, Seaborn)

### 📈 Retail Demand & Time Series Analysis
*Business Problem: How can historical sales patterns improve inventory decisions and reduce stockouts?*
- Decomposed time series to identify trend, seasonality, and anomalies
- Built and evaluated forecasting models comparing ARIMA/SARIMA and Prophet
- Metrics: MAE, RMSE, MAPE
- Tools: Python (statsmodels, Prophet, Pandas)

### 🧪 A/B Test Analysis
*Business Problem: Did a product or UX change actually improve the key metric — or was it random variation?*
- Performed hypothesis testing with proper significance thresholds and confidence intervals
- Analysed experiment results and translated statistical output into a business recommendation
- Tools: Python (statsmodels), SQL, Jupyter Notebooks
